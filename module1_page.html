Module 1: First model in an hour

Project: train an image classifier on a small public dataset. Time: about 5 hours core, plus about 3 hours for the stretch challenge.

Done when: the model trains, the loss goes down each epoch, and you report accuracy on a held-out test set.

Notes (about 10 minutes)

  • A tensor is an array that can live on a GPU. Most deep learning code is tensor manipulation.
  • A dataset returns one example. A DataLoader groups examples into batches and can shuffle them.
  • A model maps inputs to outputs. A loss function scores how wrong the output is. Lower is better.
  • The training loop repeats four steps on every batch: forward pass, compute loss, backward pass, optimizer step.
  • loss.backward() computes the gradient of the loss for every weight. optimizer.step() uses those gradients to update the weights.
  • Call optimizer.zero_grad() each step, or gradients pile up from earlier batches.
  • Always evaluate on data the model never trained on. Training accuracy alone is misleading.
  • The dataset used here, Fashion-MNIST, has 60,000 training and 10,000 test grayscale images (28 by 28 pixels) in 10 clothing classes.

Hint ladder

  1. Official PyTorch docs and a web search.
  2. The loop order is always: forward, loss, zero_grad, backward, step.
  3. model(x) gives predictions, loss_fn(predictions, y) gives the loss, optimizer.zero_grad() clears gradients, loss.backward() computes new ones, optimizer.step() updates the weights. Accuracy is (model(x).argmax(1) == y).float().mean() averaged over all test batches.
