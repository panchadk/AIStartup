Notes (about 10 minutes)

  • Data quality limits model quality. A clear labeling guide makes labels consistent; low agreement between labelers means the guide is unclear.
  • Keep a fixed test set that is never trained on or tuned on. Stamp it with a fingerprint so that reports can be compared honestly.
  • Accuracy misleads on imbalanced data: a model that always predicts the common class scores high. Use precision, recall and F1 for the class that matters.
  • Choose the metric by the cost of mistakes. If missing a positive case is costly, watch recall.
  • Check slices (groups of inputs) for unequal performance: an average can hide bias.
  • Failure analysis: group the errors into categories, then fix the biggest category first.
